# 💌 Открытка по ссылке

**Анимированная открытка с конвертом, конфетти, снегом или сердечками — отправляется ссылкой.**

### ▶️ [Открыть](https://mysik-portfolio.vercel.app/greeting-card/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- 8 поводов с готовыми текстами
- 6 оформлений и 6 эффектов частиц на Canvas
- Конверт, который открывается, и печатающийся текст
- Вся открытка хранится в ссылке
- Кнопка «Сделать свою открытку» у получателя

## Стек

JavaScript, Canvas, Web Audio. Один файл `index.html`, без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/greeting-card.git
cd greeting-card
python3 -m http.server 8000
```
